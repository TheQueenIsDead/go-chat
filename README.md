# 🎙️Go Chat

A simple chatroom application written in under 300 lines of code!

This was a fun experiment in order to gain experience with the following technologies:
 - [Go 1.22's Routing Enhancements](https://go.dev/blog/routing-enhancements)
 - [Datastar](https://data-star.dev/)
 - [Basecoat UI](https://basecoatui.com/)
 - [NATS](https://nats.io/)

I've previously relied on frameworks such as [Echo](https://echo.labstack.com/), which is wonderful! 
However, I've been curious about using only the latest Golang standard library in it's place.

## Development

In order to run a development server, use Air to provide hot reloading.

```shell
go tool air
```

Navigate to http://localhost:8080/ to get started!
